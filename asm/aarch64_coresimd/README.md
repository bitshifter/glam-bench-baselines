# asm/aarch64_coresimd

Generated by `cargo run -p ci -- bench --save --asm`. One `fns/*.s`
per function the saved benchmarks call: the gungraun core wrapper
(which holds the benchmark's inlined glam code) and non-inlined glam
functions under their demangled names. Assembly is source-annotated
(`cargo asm --rust`). Which benchmarks call a function: the
`callgrind.*.out.base@aarch64_coresimd` files.

- glam-rs commit: `6e42129fd0d177f1a061f5982c5331d4fbfb3221`
- rustc stable: `rustc 1.98.0 (88d9e12ae 2026-08-18)`
- rustc nightly: `rustc 1.100.0-nightly (f248f4038 2026-09-05)`
- valgrind: `valgrind-3.22.0`
- gungraun: `0.19.4`
- target: `aarch64-unknown-linux-gnu`
